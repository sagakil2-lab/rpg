# 모험 RPG — 웹(폴더) 버전

이 폴더를 GitHub Pages에 올리면 `https://아이디.github.io/저장소이름/` 주소로 PC·휴대폰에서 바로 플레이할 수 있어요.

## 구성
- `index.html` — 게임 본체
- `assets/` — 그림(webp)·소리(mp3)·캐릭터 기준점(anchors.js)
- `.nojekyll` — GitHub가 파일을 가공하지 않게 하는 빈 파일 (지우지 마세요)
- `로컬테스트_윈도우.bat` / `로컬테스트_맥.command` — 내 컴퓨터에서 미리 테스트

## 내 컴퓨터에서 먼저 테스트
`index.html`을 더블클릭하면 브라우저 보안 때문에 소리가 안 나와요. 대신:
- 윈도우: `로컬테스트_윈도우.bat` 더블클릭 (Python 필요)
- 맥: `로컬테스트_맥.command` 더블클릭
브라우저가 `http://localhost:8000` 으로 열려요.

## 업데이트
게임을 새로 받으면 이 폴더 내용을 통째로 덮어쓰고 다시 커밋·푸시하면 돼요. 그림 주소에 버전이 붙어 있어서 브라우저가 예전 그림을 잡고 있지 않아요.
